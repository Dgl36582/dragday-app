DragDay (iPhone) — Install & Use

This is a web app that installs like a native iPhone app (PWA).
After you add it to your Home Screen, it opens full-screen and works offline.

IMPORTANT
- It must be opened from a real website link (HTTPS) to install and work offline.
- Weather fetch needs internet, but logging runs works offline after install.

INSTALL (FASTEST PATH)
Option A: Netlify Drop (easiest)
1) Create a free Netlify account.
2) Go to the Netlify “Drop” page (drag-and-drop deploy).
3) Drag the UNZIPPED folder contents (index.html, app.js, etc.) into the page.
4) Netlify gives you a link. Open that link on your iPhone in Safari.
5) Share button → Add to Home Screen.

Option B: GitHub Pages (also free)
1) Create a free GitHub account.
2) Create a repository named dragday (or anything).
3) Upload the folder contents.
4) Turn on GitHub Pages in repo settings.
5) Open the Pages link on iPhone → Add to Home Screen.

FIRST SETUP (60 seconds)
- Race Day tab → Add Track (name + GPS lat/lon)
- Create a Race Day
- Enter Pass for each run (or paste timeslip text)

BACKUP
Export/Backup tab → Export CSV. Save it in Files (or email it to yourself).

DATA SAFETY
This app stores data locally on your iPhone (browser storage).
If you clear Safari website data, you can lose it — export CSV as your backup.
